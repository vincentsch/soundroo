# Soundroo

Make a collection of original music with your coding agent, then listen and shape it in a local studio.

Soundroo is being built as a local music toolkit: editable compositions, a listening library, synthesis, sound design, and playful voice processing. It needs no music-service account. This repository is private while development and verification are in progress.

The agent is the composer. Soundroo provides the instruments, rendering, files and studio.
